# Contributing

Thanks for your interest in Entity.

**Issues are the channel.** Bug reports, questions, and ideas are welcome as
GitHub issues. Pull requests aren't accepted yet; if that changes,
contributors will be asked to sign a Contributor License Agreement (CLA).
Please describe problems in words rather than pasting patches or third-party
code.

A good bug report includes:

- what you did, what you expected, what happened
- your platform (macOS / Linux) and Claude Code version
- relevant lines from the daemon log — but **read them before pasting**:
  logs can quote your conversations and your memories

**Never paste memory content you wouldn't publish.** Your brain is yours;
issue threads are forever.

**Security reports:** use GitHub's private vulnerability reporting (the
Security tab → Report a vulnerability), not a public issue.
